# News

## Authentication Now Required for API Access

July 27, 2026

Mark Servilla

### Description

Beginning on July 30, 2026, **EDI will require authentication for all users to access our repository REST API** as a deterrent to ongoing Denial of Service attacks and unfettered scraping of repository content. This is a continuation of our security upgrades and means that users will need to sign in to  Google, Microsoft, GitHub, or ORCiD from our Identity and Access Manager ([IAM](https://auth.edirepository.org)) service to receive a free user profile.

Once you have an EDI profile, we recommend you follow the information [here](/resources/iam) to learn how to use IAM and create an API Access Key. For coded workflows, automated scripts, and other integrations, we highly recommend switching to API access keys as an alternative to other means of authentication when using the repository REST API. API access keys are now available for you to create through your EDI user profile.

As always, please reach out to us if you have any questions, concerns, or need assistance migrating your workflows.
