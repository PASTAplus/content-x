# Working with Groups

[TOC]

A Group is a collection of user profiles used to streamline permission management across multiple data packages and individuals.

## Steps

To create or manage a group, follow these steps:

### 1. Sign-in

Sign-in to [IAM](https://auth.edirepository.org) with the identity provider of your choice.

<img class="screen-shot" src="/static/images/IAM-Sign-In.png" width="95%"> 

### 2. Select Groups

Once signed-in, select *Groups*, followed by "New Group."

<img class="screen-shot" src="/static/images/IAM-Group-View.png" width="95%"> 

### 3. Add New Group

In the "Create a new group" pop-up window, enter a new group name and an optional description, then select "Add."

<img class="screen-shot" src="/static/images/IAM-Groups-Add.png" width="95%">

### 4. Add a Member to the New Group

Once you have the "Sol Worshiper" group created, it is time to add one or more members to the group. Select the radio button to left of the "Sol Worshiper" group entry. In the "Members" panel, search for "msobol" in the "Add Users and Groups" form field and select his avatar and EDI identifier. (Note: You can search on a user or group name or EDI identifiers in this field.) The "msobol" user will then be added to the "Sol Worshipper" group.

To remove "msobol" (or any other user), select "Remove" from the "msobol" entry in the "Members" panel.
